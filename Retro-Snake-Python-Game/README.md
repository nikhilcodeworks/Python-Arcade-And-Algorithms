## 📌 Overview

**Retro-Snake-Python-Game** is a faithful recreation of the beloved arcade classic Snake. Developed with Python Turtle graphics, the game features a responsive 4-directional control scheme, dynamic snake body segment expansion upon eating food, wall and self-collision detection, and persistent scoreboards.

> [!NOTE]
> This project is designed with native web and programming standards, optimized for fast performance, high readability, and clean modular structure.

---

## ✨ Key Features

- 🕹️ **Responsive Direction Controls**: Arrow key controls (`Up`, `Down`, `Left`, `Right`) with illegal reverse-direction prevention.
- 🍎 **Randomized Food Spawning**: Food targets spawn randomly within safe playing boundary coordinates.
- 📈 **Dynamic Body Segment Expansion**: Snake grows in length with each food consumed while maintaining smooth segment following.
- 💥 **Comprehensive Collision Detection**: Instant game over detection on wall boundary impacts and tail collisions.
- 🏆 **Real-Time Scoreboard**: Displays current score and updates dynamically throughout gameplay.

## 💡 How It Works & Usage

1. Run `python main.py`.
2. Use the **Arrow Keys** (`↑`, `↓`, `←`, `→`) to steer the snake.
3. Eat the food dots to grow your snake and increase your score.
4. Avoid running into the walls or your own tail!
