## 📌 Overview

**Python-Turtle-Spirograph-Art** is a mathematical generative graphics program built with Python Turtle. By rotating circles around a central focal point at incremental angles and generating random RGB color tuples on each step, it produces stunning, complex geometric spirograph mandalas.

> [!NOTE]
> This project is designed with native web and programming standards, optimized for fast performance, high readability, and clean modular structure.

---

## ✨ Key Features

- 🎨 **Randomized 24-Bit RGB Colors**: Generates vibrant, randomized RGB color tuples (`colormode(255)`) for every drawn ring.
- 📐 **Parametric Angle Stepping**: Calculates precise geometric division angles (e.g. 5° or 10° steps) for seamless 360° symmetry.
- ⚡ **Max-Speed Rendering Engine**: Configures Turtle speed to maximum (`speed('fastest')`) for fluid hypnotic rendering.
- 🔄 **Continuous Mandala Composition**: Creates mesmerizing overlapping circular layers with perfect mathematical alignment.
