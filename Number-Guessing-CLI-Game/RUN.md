# 🚀 How to Run — Number-Guessing-CLI-Game

This application is written in Python 3 (Interactive Terminal CLI).

---

## ⚡ Option 1: 1-Click Instant Run (Windows)

Simply double-click the **`run.bat`** file in this folder!
It will instantly launch `main.py` in a dedicated console window.

---

## 🛠️ Option 2: Manual Terminal Execution

### Prerequisites
- [Python 3.8+](https://www.python.org/)
*(Note: Python Turtle Graphics and CLI libraries are included in standard Python!)*

### Commands

1. **Open terminal in this directory**:
   ```bash
   cd "Number-Guessing-CLI-Game"
   ```

2. **Run the script**:
   ```bash
   python main.py
   ```

---

## 🎮 How to Play / Interact

- Launch the script using either method above.
- Follow on-screen instructions or dialog popups.
- Enjoy the game!
