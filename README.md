## 🚀 Running Any Project Locally

Each project inside this collection is completely independent and self-contained. Navigate to any project folder to run it:

```bash
# 1. Choose any subfolder:
cd <project-folder-name>

# 2. For Web / Node projects:
npm install
npm run dev # or open index.html directly

# 3. For Python projects:
python main.py
```
